To play this mod, copy all of these files into a folder named "horde" (or any name you prefer) inside the "rerelease" directory.

Example:
C:/Program Files (x86)/Steam/steamapps/common/Quake 2/rerelease/horde

Then, in-game, open the console and enter:

game horde
exec horde.cfg
map q2dm1

Enjoy!

------

For hosting, it's recommended to place these files in the "rerelease/baseq2" folder. Since some files will be overwritten, it's a good idea to make a backup first.

KEX only lists servers running from the "baseq2" directory, so mods located in other folders won't appear in the server browser.

It's also recommended to use the DirectX 11 renderer, as it's currently the most stable.
